# Random Quote Generator

A simple, beginner-friendly terminal application in Python that displays random quotes from a curated list of 100 quotes.

## Features

- Exactly 100 unique quotes across motivational, funny, creative, tech, and life themes.
- Clean terminal-based interactive interface.
- Built using only Python's standard library (`random`, `json`, `os`).
- Robust error handling for missing or unreadable quote data.

## Running the Application

```bash
python3 app.py
```

### Commands

- `q` — Get a random quote
- `h` — Show available commands
- `x` — Exit the application
